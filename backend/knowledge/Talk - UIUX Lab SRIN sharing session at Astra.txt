flow as well as Graphical User

Page 8: UIDESIGNER
Creates a user flow document that
defines how a feature of an App or
Website works
The user flow defines multiple use
cases as well as edge cases
Deliverables are in the form of
Wireframe and/or diagrams
____
Page 9: GUIDESIGNER
Creates a Graphical User Interface for
an App or Website, based on the UI
Design (User flow)
Defines colour, sizes, fonts and
images of the Design
Deliverable are in the form hi-fidelity
Design.
____

(Master Component)

DESIGN APPROACH
Large screen area enables user to see
and interact more in 1 page
Small screen drive the pages to be
divided into multiple pages
Large screen can contain lots of
contents where the eye can travel
fast to consume.
“Less steps = better design” dogma is
best for Desktop
